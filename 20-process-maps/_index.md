# Process Maps

Each map shows the current process (as-is), the Phase 1 process (to-be) and what Phase 2 changes. Sources are in `10-observations/`.

## Main Flow

```
Worker registration ──► Ready to Work ─┐
                                       ├─► Shortlist ─► Offer ─► Employer approval ─► Dispatch ─► Shift ─► Weekly timesheet ─► QuickBooks (P1) / Phlo payroll + invoice (P2)
Client order intake ───────────────────┘                                      ▲               │
                                                                              └─ replacement ◄┘ no-show / walk-off
```

## Sub-processes

1. [Worker registration and validation](proc-01-worker-registration.md): form, validation, Ready to Work, employee code, data migration
2. [Client order intake](proc-02-order-intake.md): all channels, same-day changes, replacement orders
3. [Shortlisting, outreach and employer approval](proc-03-shortlisting-and-outreach.md): ranked shortlist, bulk offers, 1/0 replies, call prompts, approval
4. [Dispatch, no-shows and replacements](proc-04-dispatch-and-replacements.md): confirmations, site rules, daily list, no-shows, temp-to-perm
5. [Weekly timesheet to payroll](proc-05-weekly-timesheet-to-payroll.md): employer timesheet, checks, rates, QuickBooks, Phase 2 payroll and invoicing
